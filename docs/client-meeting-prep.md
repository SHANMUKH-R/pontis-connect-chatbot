## 3. Questions for the first requirements meeting
Grouped by the rubric's required topics:

**Actionable problem**
- What does success look like in one sentence? What decision/task should this help with?
- Who are the end users, and how would they use it?

**Constraints / context / examples**
- What constraints matter (budget, tools, latency, compliance, existing systems)?
- Can you walk us through 2–3 concrete examples of the problem happening?

**Data / simulation / NDA**
- What data exists, in what form, and can we access it? If not, can we simulate?
- Is an NDA needed before we see data? Who signs it?

**Success by December**
- What's the minimum outcome that would make this worthwhile by December?
- How will you judge whether we succeeded?

**Progress-update timing**
- How often do you want updates, and in what format?

**Final-presentation logistics**
- Would you attend / want a copy of the final presentation? Any format needs?
